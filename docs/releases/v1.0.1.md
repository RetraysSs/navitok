# navitok 1.0.1

A small update to 1.0.0: Windows setup, a context-size hint in the statusline, and repository cleanup.

## Update

```text
/plugin marketplace update navitok
/plugin update navitok@navitok
```

Or reinstall with `/plugin install navitok@navitok`.

## What's new

- **Context-size hint.** When the session's context reaches 150k tokens, the statusline adds `ctx 160k · checkpoint + new session`. Every message re-reads the whole context, so long sessions get expensive: in navitok's own last two sprints, one long session cost 6–8M cache-read tokens per sprint. `/navitok:checkpoint` writes the handoff, and a fresh session continues from it. Change the threshold with `"context_hint_tokens"` in `.navitok/config.json` (`0` turns it off).
- **Windows: Git Bash check.** Claude Code runs plugin hooks and the statusline through Git Bash on Windows, and falls back to PowerShell without it, where navitok's hooks fail. `/navitok:setup` now checks for a working shell. If it is missing, it shows how to install Git for Windows (https://git-scm.com/downloads/win or `winget install --id Git.Git -e`). The README Install section says the same.

## Fixes

- `plan.py` writes LF line endings on Windows too.
- The dogfood ledger's lock file is no longer tracked, and `*.lock` is gitignored.

See [CHANGELOG.md](../../CHANGELOG.md) for details. Tests: 290 pass on Windows 11 with Python 3.14.
